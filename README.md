# Luz & Sabor - Landing Page

Una *landing page* moderna y especializada en la venta de velas comestibles, diseñada para ofrecer una experiencia culinaria única. 

El objetivo de este proyecto es crear una interfaz de usuario atractiva, rápida y optimizada para la conversión, permitiendo a los usuarios descubrir el concepto de las velas comestibles, entender su funcionamiento y realizar pedidos de forma intuitiva.

---

## Características Clave

*   **Diseño Mobile-First & Responsivo:** Interfaz adaptada a cualquier dispositivo (móvil, tablet y escritorio).
*   **Enfoque UI/UX Visual:** Secciones optimizadas para capturar la atención mediante contenido interactivo y elementos visuales de alta calidad.
*   **Sección de Catálogo/Productos:** Exhibición atractiva de los diferentes sabores disponibles.
*   **Optimización de Rendimiento:** Estructura limpia y carga rápida para mejorar la experiencia de usuario.
